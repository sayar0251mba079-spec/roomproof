# RoomProof

Verified room and PG finder for students moving to Dehradun. Every listing is visited and checked in person: real photos, the full monthly cost (rent, food, electricity, deposit), distance to campus, and reviews from students who live there now. Free for students; PG owners pay a ₹2,000 placement fee per confirmed booking.

This is the MVP website (Mission 10) for the DGU Venture Quest, Individual Assignment 2.

- **Founder:** Sayar Chatterjee, DGU (0251MBA079)
- **MVP features:** verified listings with full monthly cost, filters and shortlist (up to 3), "Request a visit" via WhatsApp, tenant review layout, PG owner sign-up
- **Status:** pilot preview. Listings shown are examples until the first 25 PGs near DGU are verified.

## Run it
It is a single static page. Open `index.html` in a browser, or deploy the folder on Vercel (no build step).

## Settings
The WhatsApp number for visit requests is set at the top of the script in `index.html` (`WHATSAPP_NUMBER`).
